Vulithuba
Vulithuba is a telecommunications website with a local Node.js API, SQLite database, email/SMS notifications, and a SwiftUI iOS app.

Requirements
Node.js 20 or newer
Xcode 26 or newer for the iOS app
Dependencies installed with npm install
Run the website locally
npm install
./start-vulithuba.command
The website opens at http://127.0.0.1:3000/index.html.

The server loads configuration from .env. Copy .env.example to .env and add notification or payment credentials only on the server. Never commit .env.

Password reset
Open http://127.0.0.1:3000/forgot-password.html while the local server is running. Request a new email and use the link generated by the local server. The reset link is valid for one hour and can only be used once.

Run the iOS app
Start the local server with ./start-vulithuba.command.
Open Vulithuba/Vulithuba.xcodeproj in Xcode.
Select an iPhone Simulator.
Press Run.
The current SwiftUI MVP supports login, account details, logout, and changing the password. The simulator connects to http://127.0.0.1:3000; a physical device needs a reachable HTTPS API or a Mac LAN address.

Tests and checks
npm test
xcodebuild -project Vulithuba/Vulithuba.xcodeproj \
  -scheme Vulithuba \
  -sdk iphonesimulator \
  -configuration Debug \
  -derivedDataPath /tmp/vulithuba-derived \
  CODE_SIGNING_ALLOWED=NO build
Production deployment
The Node.js server must be deployed alongside the static files. Configure the domain and reverse proxy so /api/* routes reach server.js. Do not use production reset links until the API and reset page are deployed together.
